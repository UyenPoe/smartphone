PHONEX - STITCH SOURCE ĐÃ KHÔI PHỤC

1. Thư mục /pages/ là website responsive hiện tại.
2. Thư mục /stitch-source/ chứa SOURCE STITCH GỐC, giữ riêng để tham khảo/đối chiếu.
3. Không chỉnh trực tiếp source gốc nếu muốn bảo toàn thiết kế.
4. Mỗi original-set-XX tương ứng một ZIP Stitch gốc đã được lưu trong lịch sử dự án.
5. Các source set được tách riêng để không ghi đè file trùng tên giữa các lần export Stitch.

Khi phát triển:
- Chỉnh website chạy trong /pages/
- Đối chiếu thiết kế gốc trong /stitch-source/
