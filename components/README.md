# PhoneX Shared Components

Thư mục này chứa các thành phần giao diện (components) chuẩn hóa dùng chung của hệ thống PhoneX:

- `header.html`: Header & Navigation chuẩn hóa để chuyển thành `header.php` của WordPress hoặc layout component trong các framework.
- `footer.html`: Footer chuẩn hóa để chuyển thành `footer.php`.
- `product-card.html`: Contract template hiển thị thẻ sản phẩm (Product Card).

## Hướng dẫn sử dụng
Các component này được dùng làm khung chuẩn khi tích hợp vào CMS (WordPress/WooCommerce) hoặc các template engine (Astro, Blade, Twig) để loại bỏ việc lặp lại mã nguồn trên 46 trang tĩnh.
