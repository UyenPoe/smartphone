terminal Chạy mã nguồn Native bằng Flutter

Mã nguồn Flutter hoàn chỉnh đã được tạo tại thư mục phonex_mobile_app/. Bạn có thể mở bằng Android Studio / VS Code hoặc gõ:

$ cd phonex_mobile_app
$ flutter pub get
# Chạy trực tiếp trên Web / Chrome:
$ flutter run -d chrome
# Xuất file APK cài vào Android:
$ flutter build apk --release
