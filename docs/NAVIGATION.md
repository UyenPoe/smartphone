# PhoneX navigation

Project đã được nối navigation shell dùng chung mà không sửa markup Stitch gốc.

## Luồng chính
- Mua hàng: Home → Products → Product Detail → Cart → Checkout → Order Success → Order Tracking → Order Detail.
- Thu mua: Sell Phone → Device Selection → Valuation → Valuation Result → Sell Registration → Success → Tracking → Detail.
- Tài khoản, bảo hành, cửa hàng và khuyến mãi có menu dùng chung trên mọi trang.

`data/routes.json` là route map để dùng tiếp khi chuyển sang WordPress/router thật.
